# 教育Plus V3.0 交互原型

本版本以 GitHub V2.0（`43a65d3`）为基线，按 9 月 18 日会议方案完成 V3.0 收敛。

2026-09-21 方案 C 统一版恢复了 V2 的完整内容层级和交互密度，并把 12 个主干页面与 48 个二级页面统一为“清新校园青绿”视觉：品牌头部、校园主视觉、卡片、标签、表单状态和底部导航使用同一套设计语言。校园图片均为原型演示素材，Material Symbols 字体已随站点本地打包。

- 首页八个直接入口固定为：读书会、少年派、小记者、致青春、公益课、科学港、填志愿、订报刊；只保留图标与主标题。
- 12 个主干页面统一使用“首页 / 服务 / 活动 / 我的”四栏底部导航；48 个二级页面统一顶部返回、所属板块标题、演示标识、44px 点击区和 12px 辅助文字。
- 读书会删除打卡、积分和排行。
- “共读书会”补充学校资料、共读书目、活动动态和加入说明。
- 小记者新增独立资格申请，保留投稿、档案、电子证与作品荣誉。
- 首页及全局导航恢复 V2 板块名称：“致青春”和“公益课”。
- “致青春”将创作、社团入驻和贵州教育报主题活动拆分为三条独立路径。
- 公益课取消学段导航，改为可检索教师、课程、学段、学科和课程关键词的实时搜索。
- 科学港调整为“小小发明家”和“一起来寻宝”，取消用户提问与专家答复链路。
- 订报刊调整为数字版面预览和外部官方订阅服务说明。
- 服务页重构为“办事大厅”，不再复制首页八栏目；聚合我要投稿、小记者入驻、社团入驻、课程搜索与回放、招考政策查询、数字报刊服务和全站搜索 7 项任务。
- 办事大厅标明“公开查询 / 登录办理”，支持本地服务搜索；“我要投稿”先选择 5 种作品类型，再进入对应投稿流程。活动参与留在“活动”，进度、收藏和个人记录留在“我的”。
- 59 个内容型页面增加与当前板块相关的“继续探索”图文内容卡，图片置于对应标题与说明之后；服务页按办事任务展示 7 项测试服务，使用统一图标避免无关配图。
- 已发布作品、内容详情和活动页统一具备点赞、收藏与分享；活动聚合页的每张活动卡可单独点赞和分享。

所有人物、学校、活动和作品均为演示数据；视频号、第三方平台与官方订阅小程序均为待接入占位。
