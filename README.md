# 教育Plus V3.0 交互原型

本版本以 GitHub V2.0（`43a65d3`）为基线，按 9 月 18 日会议方案完成 V3.0 收敛。

- 首页保留八个直接入口，分为五个内容板块和三个服务工具。
- 读书会删除打卡、积分和排行。
- 小记者新增独立资格申请，保留投稿、档案、电子证与作品荣誉。
- “致青春”统一改为“教育看板”，“公益课”统一改为“公益课堂”。
- 科学港调整为“小小发明家”和“一起来寻宝”，取消用户提问与专家答复链路。
- 订报刊调整为数字版面预览和外部官方订阅服务说明。
- 个人中心和服务大厅同步移除已经取消的能力。

所有人物、学校、活动和作品均为演示数据；视频号、第三方平台与官方订阅小程序均为待接入占位。

## 本地预览

```bash
python3 -m http.server 4173
```

访问 `http://127.0.0.1:4173/`。
