# 教育Plus V3 公开浏览与登录边界

## 产品原则

- 已发布的主要内容允许游客直接浏览，包括作品正文、教育资讯、公益课程、活动详情、数字报内容和服务说明。
- 已发布作品统一提供点赞、收藏和分享。分享无需登录；点赞和收藏会写入个人记录，因此需要登录。
- 评论列表可以公开阅读；发表评论、回复、举报和关注需要登录。
- 涉及个人身份、个人记录或业务提交的页面需要登录，包括投稿、报名、社团入驻、小记者资格申请、审核进度、成长档案、消息、收藏和个人资料。

## 公开浏览页面

首页及八个业务板块、服务页、活动页，以及以下内容类页面均可免登录浏览：

- 读书会：领读课程与详情、名家文章、读后感、书库、学校读书会。
- 少年派：已发布作品、赛事详情、名师指导。
- 小记者：已发布作品、优秀小记者风采。
- 致青春：已发布校园动态、贵州教育报主题活动。
- 公益课：课程详情、直播和回放。
- 科学港：已发布科学成果、编辑答疑。
- 填志愿、订报刊：公开说明、公开数据和外部服务说明。
- 公共内容：搜索结果、教育资讯详情。

## 登录后页面

- 个人中心：我的、消息、收藏、活动记录、投稿列表、个人资料。
- 少年派：投稿表单、投稿进度、成长作品档案。
- 小记者：采写投稿、投稿进度、作品档案、荣誉证书、入驻申请、资格审核。
- 致青春：社团入驻申请、创作发布、我的发布。
- 科学港：两类作品提交、我的科学港作品。

## 互动权限

| 操作 | 游客 | 登录用户 |
|---|---|---|
| 浏览主要内容 | 可用 | 可用 |
| 分享内容 | 可用 | 可用 |
| 查看评论 | 可用 | 可用 |
| 点赞、收藏 | 提示登录 | 可用 |
| 发表评论、回复、举报、关注 | 提示登录 | 可用 |
| 投稿、报名、申请、学习进度 | 提示登录 | 可用 |
| 查看个人记录与审核进度 | 不可用 | 可用 |
